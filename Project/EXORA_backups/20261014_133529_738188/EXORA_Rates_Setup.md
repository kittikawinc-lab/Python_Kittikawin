# อัตราแลกเปลี่ยนออนไลน์ใน EXORA

โปรแกรมยังเป็น Python/Tkinter สำหรับ Windows รัน EXORA_main.py ใน VS Code ได้ตามเดิม

## เริ่มใช้งานโดยไม่ต้องมี key

ตรวจสอบ Frankfurter ตอนเปิดโปรแกรมและทุก 5 นาที ข้อมูลของแหล่งนี้เป็นอัตราอ้างอิงรายวัน ไม่ใช่ราคาสดรายวินาที ตารางแสดงคอลัมน์อ้างอิงออนไลน์แยกจากราคาซื้อ–ขายร้าน พร้อมวันที่ข้อมูลและเวลาตรวจสอบ

## เชื่อมราคาสด Twelve Data

ต้องมีบัญชีและ API key ที่มีสิทธิ์ใช้งาน currency_conversion สำหรับคู่ THB กับสกุลเงินทั้งหมดของร้าน ตรวจสอบการรองรับคู่เงิน โควตา และสิทธิ์ใช้เชิงพาณิชย์กับผู้ให้บริการก่อนเปิดใช้งาน โปรแกรมไม่สมัครบัญชีหรือซื้อบริการให้

ตั้งตัวแปรสภาพแวดล้อม Windows สำหรับผู้ใช้:

- EXORA_TWELVE_DATA_API_KEY = key ของคุณ
- EXORA_RATE_REFRESH_SECONDS = 300 (ค่าเริ่มต้น 5 นาที ปรับได้ 60–3600 วินาที)

ปิดแล้วเปิด VS Code ใหม่เพื่ออ่านค่าตัวแปร จากนั้นรัน EXORA_main.py โปรแกรมเลือก Twelve Data เมื่อพบ key และแสดงเวลาเงินจริงจากผู้ให้บริการ ไม่ใช่เพียงเวลาที่กดรีเฟรช ไม่ต้องส่ง key ในแชตหรือใส่ในไฟล์ Python

หนึ่งรอบใช้หนึ่งคำขอต่อสกุลเงินที่ไม่ใช่ THB เช่น 9 สกุลเงินคือ 9 คำขอ/รอบ การตั้งรอบสั้นต้องมีโควตาต่อนาทีและต่อวันเพียงพอ ข้อมูลต้องครบทุกสกุลเงินจึงบันทึกทั้งชุด หากคู่เงินไม่มีสิทธิ์ โควตาเต็ม หรือราคาเกิน 15 นาที ระบบแสดงดึงข้อมูลไม่สำเร็จและคงข้อมูลเดิม ไม่สลับเป็นราคาประจำวันโดยไม่แจ้ง ราคาตลาดปิดอาจไม่ใหม่พอสำหรับเงื่อนไขนี้

รุ่นนี้ตรวจสอบผ่าน REST ตามรอบ ไม่ใช่สตรีมรายวินาที ความสดและความครอบคลุมขึ้นกับบริการและบัญชีของคุณ ยังไม่ได้ตรวจสอบกับบัญชีจริงเพราะยังไม่มี key

## ใช้ราคาตลาดคำนวณราคาซื้อ–ขายร้าน

ค่าเริ่มต้นรักษาราคาที่ร้านตั้งไว้ เข้า admin → จัดการร้าน → อัตราแลกเปลี่ยน เลือก “ใช้ราคาออนไลน์คำนวณราคาซื้อ–ขายอัตโนมัติ” ตั้งส่วนต่าง 0–20% แล้วกดบันทึกและยืนยัน

ตัวอย่างราคาอ้างอิง 40 บาท ส่วนต่าง 2%: รับซื้อ 39.20 บาท ขาย 40.80 บาท ต้องปิดโหมดนี้ก่อนแก้ราคาเอง

การอัปเดตไม่เปลี่ยนประวัติ ยอดรายการที่เปิดหน้าชำระเงินแล้ว หรือใบเสร็จเดิม เมื่อทำรายการใหม่ โปรแกรมคำนวณด้วยราคาปัจจุบัน หากอินเทอร์เน็ตขัดข้องยังใช้ราคาที่บันทึกไว้ได้ โดยมีข้อความสถานะและเวลาของข้อมูลเดิม

เอกสารแหล่งข้อมูล:

- https://twelvedata.com/docs — currency_conversion: rate, symbol, timestamp
- https://twelvedata.com/forex — ข้อมูล forex สด
