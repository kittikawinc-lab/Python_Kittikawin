# ภาพประกอบ EXORA

ภาพประกอบที่ใส่ในโปรแกรมเป็นกราฟิกที่สร้างจากโค้ด EXORA_visuals.py มีเครื่องบิน หนังสือเดินทาง กระเป๋า และ boarding pass ใช้ได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

ภาพถ่ายอ้างอิงที่ค้นพบ: [Golden-hour flight โดย Astra Liu บน Unsplash](https://unsplash.com/photos/pEZ9uGCEdF4)

ยังไม่ได้รวมภาพถ่ายนี้ในโปรแกรม เพราะการดาวน์โหลดถูกปฏิเสธตามนโยบายเครือข่ายของพื้นที่ทำงาน
